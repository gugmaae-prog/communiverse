## Runtime and routing

The current site uses a Cloudflare module Worker, HTMLRewriter, native browser JavaScript and CSS, esbuild, and Node tests. `public-domain/entry.mjs` owns public routing, headers and response adaptation. `urls.mjs` owns public/legacy URL conversion. The wrapper delegates to the retained Communiverse application; MARKETPLACE, SEARCH and BOOKING remain service bindings. The same Worker handles the named Communiverse prefix on Espacios, while unrelated host/path traffic is delegated unchanged.

Public data combines existing D1 catalogue reads, curated retained modules, six artist/48-work records in public-cache.txt, public HTML snapshots, HD image metadata, 77 event/venue records, and 22 published clubs. Snapshots are public browsing fallbacks, not evidence of functioning account writes.

At reconnaissance, `/works/` redirects to Discover, `/people/` redirects to Circles without its filter, `/ambassadors/` redirects to the ambassador filter, unknown artist/person IDs return 200, and `/privacy/` and `/terms/` return 404. Home and Discover duplicate content. Circles has the recently deployed anchored profiles, image-only artworks and inline artwork stories; preserve those interactions.

## Forms, accounts and services

The shared header/footer and legacy report/club dialogs originate in retained view/client modules. Workshop HTML is generated by workshops.mjs. Workshop enquiries and event RSVPs POST to `/communiverse/api/workshop-enquiry` and `/communiverse/api/event-rsvp`; registration-notifications.mjs validates them, retains receipts for 90 days in KV and queues email through RegistrationDelivery Durable Objects. Reports and club creation use authenticated retained API handlers and D1.

Username/password accounts and sessions use D1. Google and LinkedIn OAuth use separate existing Supabase projects. Account cookies are host-only, Secure, HttpOnly, SameSite=Lax. Public pages currently route account entry to `https://espacios.me/communiverse/`. Branded account cutover must remain disabled until write capacity and both providers pass. The account-wide D1 storage total remains 12,103,135,232 bytes; read-only metadata does not establish that write failures are resolved. Google project access was verified; LinkedIn configuration access remains unverified.

Cloudflare provides hosting, KV, D1, Durable Objects, assets and email delivery. The existing verified email sender must remain until an independently verified branded sender is configured. No mail DNS or provider changes are included.

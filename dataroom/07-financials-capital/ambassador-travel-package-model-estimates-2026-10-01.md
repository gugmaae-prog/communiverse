| Key modelling assumptions |  |  |
| 1. Sponsored travellers: only Luna receives a paid fee (input B15, blank). All other ambassadors (UAE, India, Egypt, any other) are sponsored travellers whose travel is covered by this budget; fee = 0. |  |  |
| 2. Per-artisan incentive (B11) is paid on top of the travel package for every region (UAE, Colombia, India, Egypt). |  |  |
| 3. Flights are economy, round trip (international) or one way (domestic legs). Season values come from published fare data where available; shoulder is the midpoint of low and high where no direct source exists (orange cells, 'Estimate'). |  |  |
| 4. Hotels = 'modest tier': budget-hotel / guesthouse averages (Kayak-based averages via BudgetYourTrip) or local 'budget hotel' ranges. They are per ROOM per night, 1 traveller, before taxes/fees (Dubai Tourism Dirham AED 7-20/room/night is NOT included). |  |  |
| 5. Hotel nights = trip days - 1, times the 'share of nights needing paid accommodation' (Packages!O). UAE domestic uses 50% because the Dubai-based ambassador can sleep at home on some days - change to 100% for a non-Dubai ambassador. |  |  |
| 6. Local transport and food per day come from BudgetYourTrip traveller-reported averages (Daily_Costs sheet) blended by the tier weights above. Seasonal multipliers for these two lines default to 1.00 (no published seasonal data) and can be edited on Seasonal. |  |  |
| 7. International packages = round-trip Dubai flight + an in-country plan (Colombia Bogota/Medellin/Raquira, India Delhi/Jaipur, Egypt Cairo/Luxor) similar to the matching domestic package; leg counts are separate inputs on Packages. Dubai-Mumbai package assumes flying Mumbai-Delhi and back (2 extra domestic legs). |  |  |
| 8. Equipment kit (DJI Osmo Nano + tripod + memory card + contingency) is carried into every package. 'Kit allocation per trip' (Packages!Q) is 100% by default = conservative (kit charged fully to each trip). Set e.g. 50% if a kit is reused across trips. |  |  |
| 9. Not included: visas, travel insurance, vaccinations, SIM/data, activities/entry fees, checked-bag fees, airport transfers beyond local transport, tips, artisan samples/shipping, any ambassador fee. See Open_Questions. |  |  |
| 10. Meta glasses are excluded from the standard kit (restricted in some countries); only a possible future sponsored item and not in any total. |  |  |

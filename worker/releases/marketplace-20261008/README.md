# Communiverse marketplace and immediate member circles

Scoped wrapper over the captured `9563f02e-0cb5-471c-abc9-de2772678887` runtime. All 20 baseline modules remain byte-for-byte intact. Do not deploy the older top-level Next export as this release.

- Discover has 16 generated concept objects, eight craft categories, maker stories, process films and 14 display currencies. Workshop guides range from USD 38 to 95 per person. These are editorial guides, not live stock or confirmed host offers.
- 25 generated images: 16 objects and nine process illustrations. Optimized JPEGs are served as immutable Worker Data modules. Marketplace/calendar styles are embedded in HTML to respect the existing inline-only gallery style CSP. Individual preview badges are removed; one collection note distinguishes generated concepts and reference films.
- Legacy Join/Waitlist buttons now route to the same signup, including after React hydration. One Join form collects first name, craft/interest, city, email, phone and optional Instagram/TikTok handles. Consent identifies public circle fields. Phone/email, request keys and confirmation hashes never enter public JSON.
- The additive `migration.sql` creates only `cv_members`, its public index and `cv_join_limits`. Existing ambassadors, reviewer access, activity and applications are retained.
- A member circle is public immediately after the successful insert, before email confirmation. Email ownership does not confer an artist/ambassador verification badge. Existing curated ambassadors remain three.
- The restricted EMAIL binding sends from `welcome@communiverse.espacios.me`. Welcome links use opaque 256-bit tokens in the URL fragment; confirmation requires an explicit same-origin POST. Tokens are hashed, expire after seven days and are single-use. A recipient can remove an unsolicited signup through the same link.
- Duplicate-email submissions cannot overwrite a profile. A retry with the same random request key returns its existing circle without sending another welcome. Atomic per-IP hourly limits, bounded request streams, validation and Origin checks protect writes. Mail failures leave the circle public and are reported honestly in the form and private database.
- Calendar requests select craft, an artisan circle, date and group size. Requests save into the existing private applications table with a stable reference. Store enquiries carry the selected object, guide price, material and dimensions into the existing contact flow. Neither confirms an order nor charges a payment.
- Near You is a curated city guide, with official links for Pakistan, Philippines, Malaysia, China, Colombia, UAE, Saudi Arabia, Peru, India and Uzbekistan. New member artisans appear for matching cities. Optional browser location picks the nearest supported city; precise coordinates are not stored or sent to the server.
- Plug retains 640ms motion and reduced-motion support. Selection captures the circle's current centre; nearby cards make room around it. Story cards expand to natural height with visible overflow and collapse on outside interaction. The mobile video remains a small separate rounded surface.

## Reproduce and verify

For full reproduction, use the pinned 20-module pre-marketplace capture at version `9563f02e-0cb5-471c-abc9-de2772678887` and review its manifest. `scripts/prepare-marketplace.mjs <baseline-capture> <candidate>` assembles this release and verifies every retained checksum. Before a production update, independently capture and compare the actual current runtime so intervening changes are preserved. With Node 24 or later, `scripts/test-marketplace.mjs` exercises the signup/session state transitions against real in-memory SQLite and a controlled mail binding. Deploy using the guarded version-upload / zero-traffic / verification / promotion workflow recorded in `PRODUCTION.md`; preserve ASSETS, LEGACY, D1 and observability. Wrangler dry-run alone does not prove production behavior.

## Pricing and location sources (checked 8 October 2026)

Guide prices are editorial estimates informed by a small benchmark sample, not quotes for these concept artists. London pottery sessions are listed around GBP 34–40 and Bangkok ceramic sessions span different projects and group formats. See [House Pottery](https://classbento.co.uk/house-pottery) and [ClassBento Bangkok](https://classbento.co.th/pottery-classes-bangkok). The [Uncommon Goods stoneware catalogue](https://www.uncommongoods.com/sets/stoneware) provides object-price context, including USD 98 vases and smaller ceramic objects. Specialist sessions are priced higher in our guide; the final host, duration and inclusions require confirmation.

Currency conversion uses the [ExchangeRate-API open endpoint](https://www.exchangerate-api.com/docs/free), cached for 24 hours with a dated fallback. The UI includes the required provider attribution. The application endpoint returns Communiverse price quotes rather than a raw exchange-rate feed.

Official venue/visitor sources are stored directly in `data.js`: [Lok Virsa](https://lokvirsa.org.pk/heritage-museum/), [National Museum of the Philippines](https://www.nationalmuseum.gov.ph/our-museums/national-museum-of-anthropology/), [IAMM](https://iamm.org.my/), [Jingdezhen government](https://www.jdz.gov.cn/zjcd/mljdz/lylx/t932954.shtml), [Artesanías de Colombia](https://artesaniasdecolombia.com.co/PortalAC/tiendaSubMenu/tiendas_1515), [Jameel Arts Centre](https://jameelartscentre.org/), [Sharjah Art Foundation](https://www.sharjahart.org/), [Hayy Jameel](https://hayyjameel.org/), [Museo Larco](https://www.museolarco.org/), [Incredible India](https://www.incredibleindia.gov.in/en/delhi/delhi/national-crafts-museum-and-hastkala-academy), and [Uzbekistan Travel](https://uzbekistan.travel/en/o/state-museum-of-applied-art-of-uzbekistan/).
